# PageSnap Modular Component Package

- **Source:** https://dogstudio.co/
- **Component:** `<main>` (1500px × 3870px)
- **Background:** `rgb(19, 20, 25)`

## How to Use

- **Instant Preview:** Double-click `index.html` to view in any browser.
- **For AI Agents (Cursor / Claude / v0):** Feed `AI-PROMPT.md` into your agent prompt, or attach `Component.jsx` and `styles.css` directly.
- **For React / Next.js / Vite:** Copy `Component.jsx` and `styles.css` into your project:
  ```jsx
  import ExtractedComponent from './Component';
  ```

## File Inventory

- `index.html` — Standalone preview with linked styles
- `styles.css` — Clean scoped component styles and keyframe animations
- `Component.jsx` — Production-ready React JSX component
- `tokens.json` — Structured design tokens (colors, typography, dimensions)
- `AI-PROMPT.md` — Complete reverse-engineering specification for AI coding assistants
