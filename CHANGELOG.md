### Features

* Complete web component extraction to clean Markdown and standalone offline HTML.
* Floating actions dock with Smart Game HUD Coachmark for static selection.
* Live Component Studio sandbox with inline text editing and multi-file code exports.
* Visual grounding, dark/light auto-frame, and responsive authored CSS.
* Canvas WebGL detection with 60fps video recording and 3D asset packaging (BETA).
