# Repository Language Invariant

## Policy
All repository files, tracked code, documentation, test suites, rules, commit messages, and release assets in this project MUST be written in **100% English**.

## Rules
1. **Source Code & Comments**: All inline comments, function docstrings, variable names, and error messages must be in English.
2. **Documentation**: All Markdown files (`README.md`, `docs/**`, `STORE_LISTING.md`, `PRIVACY.md`) must be in English.
3. **Commit Messages & PRs**: All commit subjects, PR titles, and PR descriptions must use English adhering to Conventional Commits.
4. **No Vietnamese in Repository Files**: While conversational exchanges in developer chat may occur in Vietnamese, never commit Vietnamese text to repository files.
