# Repository Language Invariant

## Policy
All repository files, tracked code, documentation, test suites, rules, commit messages, and release assets in this project MUST be written in **100% English**.

## Rules
1. **UI & User-Facing Strings**: All button labels, dock actions, modal headers, tooltips, toast notifications, status messages, and badge texts MUST be in clear, professional English (e.g., "🔼 Expand", "🔽 Shrink", "✨ Live Studio", "🤖 AI Prompt", "🎨 Copy Component", "📝 Copy MD", "✏️ Edit Text").
2. **Source Code & Comments**: All inline code comments, docstrings, variable/function identifiers, console logs, and error strings MUST be in English.
3. **Documentation & Assets**: All Markdown documents (`README.md`, `docs/**`, `STORE_LISTING.md`, `PRIVACY.md`) MUST be written exclusively in English.
4. **Git Artifacts**: All git commit messages, branch names, PR titles, and pull request descriptions MUST adhere to English Conventional Commits.
5. **Zero Tolerance for Non-English Strings in src/**: While developer conversations in chat may use Vietnamese as requested by the user, all repository code and user-facing artifacts MUST remain 100% English for international open-source distribution.
