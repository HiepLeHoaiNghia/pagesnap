# Security Policy

## Supported Versions

Only the latest published release of PageSnap receives active security updates and patches.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of PageSnap and our users' privacy seriously. PageSnap runs 100% locally inside the browser with zero telemetry and zero external server communications.

If you discover a security vulnerability, potential cross-site scripting (XSS) bypass, or permission elevation risk:

1. **Do NOT open a public GitHub issue.**
2. Report the vulnerability privately via **GitHub Security Advisories** on this repository (preferred), or email the maintainer directly at:
   - **Email:** `hieple.dev.1209@gmail.com` (subject: `[SECURITY] PageSnap Vulnerability Report`)
3. Please include:
   - Description of the issue and potential impact.
   - Minimal reproduction steps, sample payload, or target URL.
   - Proof of Concept (PoC) code if applicable.

### Response Timeline

- **Acknowledgment:** Within 48 hours.
- **Assessment & Triage:** Within 5 business days.
- **Fix & Advisory Release:** Critical security patches will be published to the Chrome Web Store and GitHub immediately upon resolution.
